# 核心概念：模逆元
## 1. 为什么需要逆元
模运算世界中**不存在除法**，不能直接计算 $\frac{a}{b} \bmod MOD$。
我们引入「模逆元」作为等价替代：
> 除以一个数，等价于乘以这个数的模逆元

## 2. 定义
若整数 $b$ 与模数 $MOD$ 互质，则存在唯一整数 $inv(b)$，满足：

$b \times inv(b) \equiv 1 \pmod{MOD}$

此时有：

$\frac{a}{b} \equiv a \times inv(b) \pmod{MOD}$

## 3. 费马小定理求逆元
当 $MOD$ 为质数时，由费马小定理可得：

$inv(x) = x^{MOD-2} \pmod{MOD}$

通过快速幂（`qpow`）即可在 $O(\log MOD)$ 时间内计算逆元。

## 4. 求inv(x)的板子
```cpp
const int mod = 998244353; // 模
// 带模快速幂
int qpow(int x, int y) {
    int a = 1;
    while (y) {
        if (y & 1)
            a = (a * x) % mod;
        x = (x * x) % mod;
        y >>= 1;
    }
    return a;
}
// 求 x 的逆元
int inv(int x) { 
    return qpow(x, mod - 2) % mod; 
}
// 求 p/q mod意义下的逆元
int qinv(int p, int q) { 
    return p * qpow(q, mod - 2) % mod;; 
}
```

## 5. 延申：1-(a/b) 的模运算写法
令 p = qinv(a, b); p 为概率 a/b 的模逆元
则 1-(a/b) 的模逆元为
```cpp
(mod + 1 - p) % mod
```
- 用于计算 $1-p$ 的模值
- 先加 `mod` 再取模，是为了避免减法导致负数结果
