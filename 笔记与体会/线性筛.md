# 线性筛（欧拉筛）笔记
## 1. 核心原理
线性筛保证**每个合数只会被它最小质因子筛一次**，时间复杂度严格 $O(n)$，优于埃氏筛 $O(n\log\log n)$。

### 关键逻辑
1. 遍历 $i$ 从 2~n：
   - 若 $i$ 未标记为合数 → $i$ 是质数，加入质数数组 `primes`
2. 枚举已存质数 $p$：
   - 若 $i \times p > n$，超出范围直接 break
   - 标记 $i\times p$ 为合数
   - 若 $i \bmod p == 0$，立刻 break：
     $p$ 是 $i$ 的最小质因子，后续更大质数与 $i$ 的乘积，会在更大 $i'$ 时被 $p$ 筛除，避免重复标记。

## 2. C++ 标准代码
```cpp
#include<bits/stdc++.h>
using namespace std;

// 线性筛：n为上限，primes输出质数列表
void linearSieve(int n, vector<int>& primes) {
    vector<bool> isComposite(n+1, false); // 标记合数，初始全false
    for (int i = 2; i <= n; i++) {
        if (!isComposite[i]) {
            primes.push_back(i);
        }
        // 枚举所有已找到的质数
        for (int p : primes) {
            if (1LL * i * p > n) break; // 防溢出，转long long
            isComposite[i * p] = true;
            if (i % p == 0) break; // 核心终止条件
        }
    }
}

// 使用示例
int main() {
    vector<int> primes;
    linearSieve(100, primes);
    for (int x : primes) cout << x << " ";
    return 0;
}
```

## 3. 易错点
1. **乘法溢出**：$i \times p$ 可能超 int 范围，建议写成 `1LL * i * p` 判断边界
2. 循环终止顺序：先判 $i\times p>n$，再标记合数，最后判 `i%p==0` break
3. 数组下标：筛 $[2,n]$，布尔数组大小必须开到 $n+1$

## 4. 优缺点
### 优点
- 线性时间，大数据量效率远高于普通埃氏筛
- 可同步得到质数表，能拓展求欧拉函数、最小质因子、莫比乌斯函数等积性函数

### 缺点
- 常数略大于简单埃氏筛，小数据差距不明显

## 5. 拓展方向
基于线性筛可预处理积性函数：
- 最小质因子 `minp[]`
- 欧拉函数 $\varphi(x)$
- 莫比乌斯函数 $\mu(x)$
- 约数和、约数个数等
