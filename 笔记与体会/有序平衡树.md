# PBDS 有序平衡树（名次树）完整指南

> 本文档为 GNU 扩展库 `__gnu_pbds`（Policy-Based Data Structures）中基于红黑树实现的**有序平衡树（名次树）**使用笔记。相比标准库 `std::set`，额外支持「按值查排名」「按排名查值」两种核心操作，是算法竞赛中处理动态名次问题的常用工具。

---

## 一、有序平衡树的构建

### 1.1 必备头文件与命名空间
提供两种引入方式，可根据编译环境选择：

```cpp
// 方式一：GNU 扩展万能头（推荐，一站式包含所有 pbds 组件）
#include <bits/extc++.h>

// 方式二：仅引入平衡树必需头文件
// 部分精简编译器（如旧版 TDM-GCC）下兼容性更好，可避免 iconv.h 缺失报错
// #include <ext/pb_ds/assoc_container.hpp>
// #include <ext/pb_ds/tree_policy.hpp>

// 必须启用命名空间，否则无法直接使用 tree 相关类型
using namespace __gnu_pbds;
```

### 1.2 常用模板别名定义
为了简化代码，通常使用 `using` 封装常用模板：

```cpp
// 1. 去重有序集合（等价于带排名功能的 std::set）
template <typename T>
using ordered_set = tree<T, null_type, less<T>, rb_tree_tag, tree_order_statistics_node_update>;

// 2. 可重复有序集合（等价于带排名功能的 std::multiset）
template <typename T>
using ordered_multiset = tree<T, null_type, less_equal<T>, rb_tree_tag, tree_order_statistics_node_update>;

// 3. 有序映射（等价于带排名功能的 std::map）
template <typename Key, typename Value>
using ordered_map = tree<Key, Value, less<Key>, rb_tree_tag, tree_order_statistics_node_update>;
```

### 1.3 模板参数逐个详解
`tree` 模板共 5 个参数，含义依次如下：

| 参数位置 | 参数示例 | 详细说明 |
|----------|----------|----------|
| 第 1 位 | `int` / `T` | **键类型**：存储的元素类型，支持 `int`、`long long`、`pair` 等可比较的类型 |
| 第 2 位 | `null_type` / `string` | **映射值类型**：<br>- `null_type`：无映射值，对应集合模式（set），只存键<br>- 填入具体类型：对应映射模式（map），存储键值对 |
| 第 3 位 | `less<int>` / `less_equal<int>` | **排序规则**：<br>- `less<T>`：严格升序，键唯一（自动去重）<br>- `less_equal<T>`：升序，允许重复键<br>- `greater<T>`：严格降序 |
| 第 4 位 | `rb_tree_tag` | **底层实现**：<br>- `rb_tree_tag`：红黑树（自平衡二叉搜索树，最常用）<br>- 可选 `splay_tree_tag`（伸展树）、`ov_tree_tag`，竞赛场景几乎不用 |
| 第 5 位 | `tree_order_statistics_node_update` | **节点更新策略**：开启名次统计功能，**必须填写**，否则无法使用名次查询函数 |

## 二、核心独有函数（std::set 不具备）
以下两个函数是 pbds 平衡树的核心价值，设树对象名为 `tr`。

### 2.1 `order_of_key(x)`：按值查排名
- **功能**：返回**严格小于 x 的元素个数**，即 x 的排名（从 0 开始计数）
- **时间复杂度**：$O(\log n)$

#### 代码示例
```cpp
ordered_set<int> tr;
tr.insert(1);
tr.insert(3);
tr.insert(5);

cout << tr.order_of_key(3);  // 输出 1 （小于 3 的元素有 1 个：1）
cout << tr.order_of_key(4);  // 输出 2 （小于 4 的元素有 2 个：1, 3）
cout << tr.order_of_key(0);  // 输出 0 （不存在小于 0 的元素）
```

### 2.2 `find_by_order(k)`：按排名查值
- **功能**：返回**第 k 小元素的迭代器**（k 从 0 开始计数）
- **时间复杂度**：$O(\log n)$
- 若 k 越界（大于等于元素总数），返回 `tr.end()`

#### 代码示例
```cpp
ordered_set<int> tr;
tr.insert(10);
tr.insert(20);
tr.insert(30);

cout << *tr.find_by_order(0);  // 输出 10 （第 0 小，即最小值）
cout << *tr.find_by_order(2);  // 输出 30 （第 2 小，即最大值）
```

### 2.3 组合使用示例
在可重集中定位第一个等于 x 的元素：
```cpp
ordered_multiset<int> tr;
tr.insert(5);
tr.insert(5);
tr.insert(7);

int first_pos = tr.order_of_key(5);  // 第一个 5 的排名：0
cout << *tr.find_by_order(first_pos); // 输出 5
```

## 三、常用操作与避坑指南

### 3.1 基础操作汇总
| 操作 | 代码 | 说明 |
|------|------|------|
| 插入元素 | `tr.insert(x)` | 自动维护有序与树的平衡 |
| 查找元素 | `tr.find(x)` | 返回迭代器；找不到返回 `tr.end()` |
| 获取元素总数 | `tr.size()` | 返回树中元素个数 |
| 判空 | `tr.empty()` | 树为空返回 `true` |
| 清空树 | `tr.clear()` | 移除所有元素 |
| 首尾迭代器 | `tr.begin()` / `tr.end()` | 支持范围 for 遍历 |
| 二分查找 | `tr.lower_bound(x)` / `tr.upper_bound(x)` | 用法与 `std::set` 完全一致 |

### 3.2 重点避坑：可重集的单个元素删除
⚠️ **高频易错点**：在 `less_equal<T>`（可重集）模式下，直接执行 `tr.erase(x)` 会**删除所有值等于 x 的元素**，而非只删一个。

✅ **正确删除单个元素的方法**：先通过排名定位到单个元素的迭代器，再删除迭代器
```cpp
// 删除可重集中第一个等于 x 的元素
// 方式一
auto it = tr.upper_bound(x);

// 方式二
// auto it = tr.find_by_order(tr.order_of_key(x));

tr.erase(it);
```

#### 完整示例
```cpp
ordered_multiset<int> tr;
tr.insert(5);
tr.insert(5);
tr.insert(5);

// 错误写法：会一次性删除全部 3 个 5
// tr.erase(5);

// 正确写法：只删除 1 个 5
tr.erase(tr.upper_bound(5));
// 执行后树中还剩 2 个 5
```

### 3.3 排名下标从 0 开始
- 最小元素对应排名 `0`，通过 `find_by_order(0)` 获取
- 最大元素对应排名 `tr.size() - 1`
- `order_of_key(x)` 返回的是**严格小于 x 的数量**，不是小于等于

### 3.4 `less` 与 `less_equal` 选型对比
| 对比项 | `less<T>` | `less_equal<T>` |
|--------|-----------|-----------------|
| 重复元素 | 自动去重，键唯一 | 允许重复键 |
| `erase(x)` 行为 | 删除单个匹配元素 | 删除所有匹配元素 |
| `find(x)` 行为 | 精准匹配，行为稳定 | 行为不稳定，不推荐使用 |
| 适用场景 | 元素唯一的名次问题 | 可重复元素的名次问题 |

> 最佳实践：可重集场景下，优先使用 `order_of_key + find_by_order` 定位元素，尽量避免直接调用 `find`。

### 3.5 有序映射（map 模式）注意事项
1. **不支持 `[]` 下标运算符**，只能通过 `insert({key, value})` 插入，通过 `find(key)` 访问值
2. 名次查询仅针对 `key` 排序，与 `value` 无关
3. **不推荐搭配 `less_equal` 使用**，重复键会导致迭代器、查找逻辑出现未定义行为

### 3.6 编译环境说明
- 仅支持 **GCC / MinGW-w64** 编译器，MSVC（Visual Studio）不支持该 GNU 扩展
- 若使用 TDM-GCC 出现 `iconv.h` 缺失报错，建议更换为 MSYS2 版 MinGW-w64，或改用分开的两个 pbds 头文件
