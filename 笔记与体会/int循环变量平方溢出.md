C++ 刷题经典致命陷阱：int 循环变量平方溢出（死循环 TLE）

## 📝 问题场景

在**枚举约数、根号遍历**的经典模板中：遍历 $$\sqrt S$$ 寻找因数，若书写不规范会直接触发**整数溢出 + 死循环**，导致全程 TLE，且逻辑看上去完全正确，极难排查。

## 🐛 错误代码（会超时）

变量 `s` 是 64 位长整型，但循环变量为 `int`：

```
ll s;
cin >> s;
// 致命错误：d 是 int
for (int d = 1; d * d <= s; d++) {
    if (s % d == 0) {
        divs.push_back(d);
        if (s / d != d) divs.push_back(s / d);
    }
}
```

## 💥 溢出原理（核心）

1. **运算类型由操作数决定**：`int * int` 结果永远是 `int`，不会自动提升为 long long。
2. 32位 int 上限：`2147483647`。当 $$d > 46340$$ 时，`d*d` 溢出。
3. 有符号整数溢出属于 **未定义行为(UB)**，数值会变成负数/乱码。
4. 负数恒小于 $$10^{12}$$，`d*d <= s` 永久成立 →**for 死循环 → TLE**。

## ✅ 正确写法（AC 标准模板）

```
ll s;
cin >> s;
// 循环变量必须为 long long
for (ll d = 1; d * d <= s; d++) {
    if (s % d == 0) {
        divs.push_back(d);
        if (s / d != d) divs.push_back(s / d);
    }
}
```

## 📌 通用结论 & 刷题铁律

只要满足以下场景，**循环变量必须开 long long**：

- 循环条件包含 `i * i`
- 数据范围最大到 $$10^{12}$$ / $$10^9$$ 级别

**永远不要用 int 做平方判断遍历！**

## 💡 快速排查口诀

**平方遍历不用int，大数循环必开ll**
