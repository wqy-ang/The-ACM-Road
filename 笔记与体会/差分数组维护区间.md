# 差分数组维护多区间，判断位置i是否被区间覆盖
> 场景：给若干 $[l,r]$，对每个下标 $i$，快速知道 `i 是否落在至少一个区间里面`。

## 核心原理
差分数组 `diff`：
- 区间 $[l,r]$ 覆盖：`diff[l] += 1`，`diff[r+1] -=1`
- 做前缀和 `sum[i]`：`sum[i] > 0` ⇒ i 在某个区间内；`sum[i]==0` ⇒ i不在任何区间。

> 注意数组下标：一般题目下标从 **1开始**；如果是0下标数组要微调 r+1 越界问题。

### 步骤
1. 初始化差分数组 diff，大小为 $n+2$（防止 r+1 越界，这是竞赛常用小技巧），初始全0。
2. 对每一个给定区间 $[l, r]$：
```cpp
diff[l]++;
diff[r+1]--;
```
3. 遍历i从1~n，一边算前缀和cnt，一边判断：
```cpp
int cnt = 0;
for(int i = 1; i <= n; i++){
    cnt += diff[i];
    if(cnt > 0){
        // i 处于至少一个区间内
    }else{
        // i 不在任何区间
    }
}
```

### 完整最小示例(C++，下标从1)
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main(){
    int n = 10;
    vector<int> diff(n + 2, 0); // n+2避免r+1越界

    // 添加区间 [2,4], [6,8]
    diff[2]++; diff[5]--;
    diff[6]++; diff[9]--;

    int cnt = 0;
    for(int i = 1; i <= n; ++i){
        cnt += diff[i];
        if(cnt > 0){
            cout << i << " 在区间内\n";
        }else{
            cout << i << " 不在区间\n";
        }
    }
    return 0;
}
```

输出：
```
1 不在区间
2 在区间内
3 在区间内
4 在区间内
5 不在区间
6 在区间内
7 在区间内
8 在区间内
9 不在区间
10 不在区间
```

## 如果数组下标是 0 开始
区间 $[l,r]$（0下标，包含两端）
```cpp
diff[l]++;
diff[r+1]--;
```
diff数组开 `n+2`；遍历i从0到n‑1，同样累加cnt。

## ⚠️边界坑点（竞赛高频踩坑）
1. **r = n 的时候**：`r+1 = n+1`，所以diff数组必须开到 `n+2`，不然数组越界RE。
2. 差分数组本身**不能直接判断i是否在区间**！必须求前缀和后的cnt才代表当前位置被多少个区间覆盖。diff只是记录变化点。
3. 如果只是想知道“是否被覆盖”不需要精确计数，依然用`cnt>0`判断，不要用diff[i]。

## 时间复杂度
- m个区间：$O(m+n)$，非常高效，适合n很大（$10^5,10^6$）的数据。

## 拓展：如果需要多次查询单点i（不是顺序遍历）
如果你不是顺序遍历1~n，而是随机查询某个i是否被覆盖：
那就把前缀和全部预处理出来存到`cover[]`数组，之后 $O(1)$ 查询：
```cpp
vector<int> cover(n+1,0);
int cnt=0;
for(int i=1;i<=n;i++){
    cnt += diff[i];
    cover[i] = cnt;
}
// 查询 i： if(cover[i]>0) ...
```

## 和别的做法对比
- 暴力：每个区间循环l~r打标记 $O(mn)$，n大直接超时。
- 差分数组：$O(m+n)$，本题最优。
- 离散化：当n极大（$10^{18}$）但是区间数量m很小，不能开数组，改用事件点排序扫描线。

### 扫描线思想（n巨大无法开数组时）
把所有`(l, +1)`、`(r+1, -1)`存起来排序，然后离线处理。这个就是差分数组的离散版本。

---

### 总结一句话
> 差分数组记录区间的增减标记，**遍历的时候维护运行前缀和cnt，cnt>0代表i落在至少一个区间内**。
