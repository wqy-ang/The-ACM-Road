

# 二分算法笔记（开区间版本）
> 2026-08-18

## 1. lower_bound 开区间模板 C++
功能：返回数组中**第一个 ≥ target** 的元素下标；找不到返回数组长度 `n`。
```cpp
int lower_bound(vector<int>& nums, int target) {
    // 开区间 (left, right)
    int left = -1, right = nums.size();
    // 循环不变量
    // nums[left] < target
    // nums[right] >= target
    while (left + 1 < right) { // 开区间不为空
        int mid = left + (right - left) / 2; // 防溢出写法
        if (nums[mid] >= target) {
            right = mid; // 缩小到 (left, mid)
        } else {
            left = mid;  // 缩小到 (mid, right)
        }
    }
    // 循环结束 left+1 == right
    // nums[left] < target，nums[right] >= target
    return right;
}
```

## 3. 基于 lower_bound 的常用转化表
| 需求                   | 写法                      | 不存在时结果 |
| ---------------------- | ------------------------- | ------------ |
| ≥ x 的第一个元素下标   | `lowerBound(nums, x)`     | `n`          |
| > x 的第一个元素下标   | `lowerBound(nums, x+1)`   | `n`          |
| < x 的最后一个元素下标 | `lowerBound(nums, x)-1`   | `-1`         |
| ≤ x 的最后一个元素下标 | `lowerBound(nums, x+1)-1` | `-1`         |

### 统计元素个数
| 需求           | 写法                        |
| -------------- | --------------------------- |
| < x 的元素个数 | `lowerBound(nums, x)`       |
| ≤ x 的元素个数 | `lowerBound(nums, x+1)`     |
| ≥ x 的元素个数 | `n - lowerBound(nums, x)`   |
| > x 的元素个数 | `n - lowerBound(nums, x+1)` |

> 补充：`<x` 和 `≥x` 互为补集，数量相加等于数组长度 n；`≤x` 和 `>x`同理。

## 4. mid 为什么写 `left + (right‑left)/2`
- 不推荐 `(left+right)/2`：当 left、right 很大接近 int上限时，`left+right` 会**整数溢出**，得到错误mid。
- `left + (right‑left)/2` 等价数学结果，但不会把两个大数相加，规避溢出。
- Python 整数无溢出，两种写法都可以。

## 5. 开区间二分优点
1. **循环不变量清晰**：`left`、`right` 的语义全程固定，不容易写乱边界。
2. **不需要在循环内部手动保存答案**：`if` 条件成立更新哪个变量，最后就返回哪个变量，等价于“边二分边记录答案”的写法，代码更简洁。
3. 边界统一：`left=-1`，`right=n`，天然兼容目标在数组最前面、完全不存在、在数组末尾的情况。
4. 模板高度复用：可以直接套到“二分答案”题目（不是找数组下标，猜整数答案）。

## 6. 注意事项
1. **循环条件固定**：`while(left + 1 < right)`，不要写成 `left < right` / `left <= right`，这是开区间写法的核心。
2. **循环不变量不能破坏**
   - `left`：永远代表不满足条件的一侧
   - `right`：永远代表满足条件的一侧
3. 循环结束后必然满足 `left+1 == right`，返回 `right`（最小满足条件的值）。
4. 处理下标越界：
   - 当结果为 `-1` 代表没有 `<x` 的元素；
   - 结果等于 `n` 代表没有 `≥x` 的元素。
5. mid 溢出问题：C++/Java 等强类型语言务必优先 `left + (right-left)/2`。
6. 数组必须**有序**才能使用 lower_bound。

## 7. 记忆口诀
> 开区间 `(left, right)`
> - check(mid) 为 true → `right = mid`
> - check(mid) 为 false → `left = mid`
> - 循环结束返回 `right`
