# 分解质因数的小思

将一个正整数 n 分解成若干个质因数，例如：18 分解成 2 * 3 * 3。

```c++
// https://www.nowcoder.com/share/jump/1610711571786782117478
#include <bits/stdc++.h>
using namespace std;

int main() {
    long long n;
    cin >> n;
    vector<long long> ans;

    for (long long i = 2; i*i <= n; i++) {
        while (n % i == 0) {
            ans.push_back(i);
            n /= i;
        }
    }
    if (n > 1)
        ans.push_back(n);

    for (int i = 0; i < ans.size(); i++) {
        if (i)
            cout << ' ';
        cout << ans[i];
    }
    cout << '\n';
}
```

重最小的质数开始除，直到除不动 i ++，这天然保证了放入数组的是质数，因为非质数一定会被更小的质数除掉。
