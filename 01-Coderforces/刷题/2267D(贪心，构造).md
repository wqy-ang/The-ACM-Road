## 题目简述：

**hill（山峰数组）定义**：存在一个位置 k，数组前 k 项严格递增，从 k 开始往后严格递减（k 就是峰顶）。

给定由互不相同整数组成的数组 a，你可以**任意次**执行操作：选下标 i，交换 \(a_i\) 和 \(a_{i+2}\)。

> 这个操作等价于：**奇数位置之间可以自由重排；偶数位置之间可以自由重排**，奇数位和偶数位的元素不能互相交换。

问：能否通过上述操作，把数组变成山峰数组。

输入多组测试用例，输出 YES / NO。

## 思路简述：

1. 根据奇偶位置分开存数组


2. 贪心的重最小的数开始放，放在两边，同时根据两端位置奇偶性来判断放入的可行性

## 代码：

```c++
void solve() {
    int n;
    cin >> n;
    vector<int> od, ev;
    for (int i = 0; i < n; ++i) {
        int x;
        cin >> x;
        if (i % 2 == 0) {
            od.push_back(x);
        } else {
            ev.push_back(x);
        }
    }

    // sort
    sort(od.begin(), od.end());
    sort(ev.begin(), ev.end());
    
    int i=0, j=0;
    int l=0, r=n-1;
    for(int st=0; st<n; st++) {
        int x, op;
        if(i<od.size()&&j<ev.size()) {
            if(od[i] < ev[j]) {
                x = od[i];
                i++;
                op = 0;
            } else {
                x = ev[j];
                j++;
                op = 1;
            }
        } else if(i<od.size()) {
            x = od[i];
            i++;
            op = 0;
        } else {
            x = ev[j];
            j++;
            op = 1;
        }

        bool canl = (l%2==op);
        bool canr = (r%2==op);

        if(!canl && !canr) {
            cout << "NO\n";
            return;
        }

        if(canl) {
            l++;
        } else {
            r--;
        }
    }

    cout << "YES\n";
}
```

## 另一思路：

1. 从最大值开始贪心
2. 用 $pos$ 数组记录从 1 到 n 的数所在位置的奇偶性
3. 用一个 整数变量 $c$ 来维护已构造山丘两端的奇偶位置状态

## 代码：

```C++
void go() {
    int n; cin >> n;
    vector<int> pos(n+1, 0);

    for(int i=0; i<n; i++) {
        int x; cin >> x;
        pos[x] = i%2;
    }

    int c, flag=0;
    // c 表示已构造山丘两端 奇位置个数
    if(pos[n]) c=2;
    else c=0;

    for(int i=n-1; i>0; i--) {
        if(pos[i]) c++;
        else c--;
        if(c > 2 || c < 0) {
            cout << "NO\n";
            return;
        }
    }

    cout << "YES\n";
}
```
