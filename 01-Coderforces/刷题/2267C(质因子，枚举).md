# 动态规划枚举到认清本质

> 2026-09-26
>
> [Problem - C - Codeforces](https://codeforces.com/contest/2267/problem/C)

## 题目简述：

输入整数 n 和 x，输入 n 个整数 $a[1],a[2],...,a[n]$ 。每次操作：选合法堆，取走 $ g=gcd(a_i,x)$ 个硬币，同时把 x 改成 g；自选操作顺序，最大化总偷币数。当所有 $gcd(a_i,x)=1$ 时停止。

## 思路简述：

关键点1：如果 $a_i\%x==0$ 那么 $a_i$ 可以全部取走。

关键点2：$x_1$ 和 $x_2$ 都是 $x$ 的因子，且 $x_1$ 又是 $x_2$ 的因子，那么  $x_2$ 能取走的数， $x_1$ 也能取走。

所以可以提取 $x$ 的所有因子放入 $divs$ 。遍历数组 $a$ ，每个元素与 $x$ 求最大公约数，将元素累加进对应因子能取走的数 $sum[i]$ 。再遍历 $x$ 的因子，将因子的因子也进行累加，最后取最大 $max(sum[i])$ 。

## 代码

```c++
// 获取因子
vector<int> get_div(int n) {
    vector<int> divs;
    for (int i = 1; i * i <= n; ++i) {
        if (n % i == 0) {
            divs.push_back(i);
            if (i * i != n) {
                divs.push_back(n / i);
            }
        }
    }
    sort(divs.begin(), divs.end());
    return divs;
}

void solve() {
    int n, x;
    cin >> n >> x;
    vector<int> a(n);
    for (int &x : a)
        cin >> x;

    vector<int> divs = get_div(x);
    int k = divs.size();
    vector<int> sum(k, 0);

    for (int i = 0; i < n; ++i) {
        int g = __gcd(a[i], x);
        int idx = lower_bound(divs.begin(), divs.end(), g) - divs.begin();
        sum[idx] += a[i];
    }

    vector<int> f = sum;
    for (int i = 0; i < k; ++i) {
        for (int j = i + 1; j < k; ++j) {
            if (divs[j] % divs[i] == 0) {
                f[i] += sum[j];
            }
        }
    }

    int ans = 0;
    for (int i = 0; i < k; ++i) {
        if (divs[i] > 1) {
            ans = max(ans, f[i]);
        }
    }

    cout << ans << "\n";
}
```

## 思路优化：

对于 $x$ 的因子，有最小单位元，就是质因子，质因子之间没有倍数关系，对于某个质因子，我们可以在数组 $a$ 中找所有能整除该质因子的值，将该值累加，最终得到的总和就是该质因子能取得的最大值。对每个质因子都进行这样的操作，求最大值即为答案。特别的，如果 $x>1$ $x$ 本身也要尝试求一遍，保证完备。优化后的代码更加简短。

## 优化代码：

```c++
int a[300005];
int n;
int check(int x) {
    int ans = 0;
    for(int i=0; i<n; i++) {
        if(a[i]%x == 0) ans+=a[i];
    }
    return ans;
}
void go() {
    int x;
    cin >> n >> x;
    for(int i=0; i<n; i++) cin >> a[i];

    int ans = 0;
    for(int i=2; i*i<=x; i++) {
        if(x%i == 0) ans = max(ans, check(i));
        while(x%i==0) x/=i;
    }
    if(x>1) ans = max(ans, check(x));

    cout << ans << '\n';
}
```

## 小结：

这题的本质就是探索最大公约数和因子之间的关系，认清因子与质因子之间的关系。
