# L. 登山对决
> 做题时间：2026-07-24
> 竞赛：2026牛客暑期多校训练营3
> 原题链接：https://ac.nowcoder.com/acm/contest/133878/L
## 题目简述
给定一张 $n\times m$ 的高度网格，两名玩家进行登山博弈游戏，规则如下：
1. 游戏开局给定起始格子，由先手率先行动；
2. 每一轮操作时，玩家只能移动到**上下左右四邻**中高度**大于等于当前格子**的相邻方格；
3. 若玩家当前所在格子四周不存在合法可移动方格（该格为局部山峰，四周所有相邻格子高度都低于自身或超出边界），当前行动玩家无法操作，直接判负。

多组询问，每组给出一组坐标作为游戏起点，请输出该局面下先手必胜（First）或先手必败（Second）。

## 做题思路
做这道题要理清这几个关键点：
Hint1：对于局部最高格子（即上下左右对比自己，更低或者不存在），一定是先手必输。
Hint2：对于其它格子，只要四周（上下左右）存在一个格子先手必输，则这个格子先手必胜。反之四周全为先手必胜，则这个格子先手必输。

如此一来，这道题就变得简单起来了。我们用一个二维数组win记录每个格子先手必胜的情况（1：先手必胜、0：先手必输、-1：未标记），接着以输入询问的坐标为起点 DFS 到局部最高格子或已标记格子，逐格递归，逐格记忆化标记。只要是走过的路都会缓存结果，大幅降低多组询问的重复计算开销。

## 完整代码
```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long

int n, m;
vector<vector<int>> a, win; // a 存图；win 记录先手必胜情况
int tx[] = {-1, 0, 1, 0};
int ty[] = {0, 1, 0, -1};
// 判断坐标是否在图内
bool hasway(int x, int y) { return x >= 0 && y >= 0 && x < n && y < m; }
// 判断该点是否为山峰（即局部最高点）
bool noway(int x, int y) {
    bool s[4];
    for (int i = 0; i < 4; i++) {
        int dx = x + tx[i];
        int dy = y + ty[i];
        if (!hasway(dx, dy)) {
            s[i] = false;
        } else {
            if (a[dx][dy] < a[x][y])
                s[i] = false;
            else
                s[i] = true;
        }
    }
    return !s[0] && !s[1] && !s[2] && !s[3];
}
// 深度搜索至山峰或已经标记过的点
int dfs(int x, int y) {
    // 若已标记则直接返回
    if (win[x][y] != -1)
        return win[x][y];
    // 若为山峰则直接返回
    if (noway(x, y)) {
        win[x][y] = 0;
        return 0;
    }
    int cnt = 0; // 记录该点必胜方向数量
    for (int i = 0; i < 4; i++) {
        int dx = x + tx[i], dy = y + ty[i];
        if (!hasway(dx, dy))
            continue;
        if (a[dx][dy] < a[x][y])
            continue;
        int ok = dfs(dx, dy);
        if (ok == 0)
            cnt++;
    }
    if (cnt > 0) {
        win[x][y] = 1;
    } else
        win[x][y] = 0;
    return win[x][y];
}
void solve() {
    // 输入部分
    cin >> n >> m;
    win.assign(n, vector<int>(m, -1));
    a.assign(n, vector<int>(m));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> a[i][j];
        }
    }
    // 询问部分
    int q;
    cin >> q;
    while (q--) {
        int x, y;
        cin >> x >> y;
        x--, y--; // 图从下标0开始存的
        int ok = dfs(x, y);
        if (ok == 1)
            cout << "First\n";
        else
            cout << "Second\n";
    }
}
signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--)
        solve();
    return 0;
}
```
## 反思
1. 最初开全局变量为
```cpp
const int N = 1e5 + 5;
int a[N][N], win[N][N];
```
初始化为
```cpp
memset(win, -1, sizeof win);
```
这导致静态二维数组尺寸过大，栈/堆内存直接溢出，程序无法正常输出。
后全局变量修正为动态二维容器
```cpp
vector<vector<int>> a, win;
```
每次单组测试用例按需分配内存：
```cpp
win.assign(n, vector<int>(m, -1));
a.assign(n, vector<int>(m));
```
按需开辟空间，规避超大静态数组内存超限问题。

2. dfs() 函数坐标偏移写错，把 tx 写成 ty，写成
```cpp
int dx = x + ty[i], dy = y + ty[i];
```
调试很久都没定位到bug，在同学喻的帮助下才修正为正确写法：
```cpp
int dx = x + tx[i], dy = y + ty[i];
```

3. Easy
