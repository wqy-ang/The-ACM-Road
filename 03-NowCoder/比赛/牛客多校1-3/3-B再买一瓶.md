# B. 再买一瓶

## 题目简述
初始拥有 $n$ 元现金，一瓶饮料售价1元；每瓶饮料有 $\dfrac{a}{b}$ 的概率中奖，中奖后可免费多喝 $c$ 瓶。
我们需要喝满恰好 $m$ 瓶饮料，且恰好把身上 $n$ 元全部花完，求该事件发生的概率，答案对 $998244353$ 取模。
若不存在合法方案，直接输出 $0$。

## 思路与问题
赛时的总体思路没有问题，题目思路也比较简单，先是判断能不能喝到m瓶花光所有钱，如果不能就输出 0，然后对于 喝到m瓶花光所有钱 的中奖次数是惟一且确定的 中奖数为0答案就是 mod=998244353 意义下的 $(1-a/b)^m$。中奖数大于0，答案就是 $cnt \cdot (1-a/b)^{m-k} \cdot (a/b)^k$， $k$ 为中奖数， $cnt$ 为喝到m瓶花光所有钱中奖k次的所有情况数量。

赛时的问题就出在 $cnt$ 的计算，这道题目的难点也在这里。

题解中提到了 **Raney 引理**：若整数序列每一项不超过 1，总和为正整数 $n$，则它的 $m$ 个循环移位中恰有 $n$ 个移位的所有非空前缀和为正。

将喝饮料的过程逆向来看就相当于 卖一瓶普通饮料得 $1$ 元，卖一瓶中奖饮料得 $1-c$ 元，最终共卖出 $m$ 瓶，收益 $n$ 元。对应Raney定理就是，长度为 $m$ 的序列，总和为 $n$，保证序列循环顺序不变的情况下，可以产出 $n$ 个所有非空前缀和为正的序列。

在一个 长度为 $m$ 循环序列中选 $k$ 个元素，就像在 $m$ 个椅子的圆形桌坐 $k$ 个人（每个人都一样），总情况数就是 $\dfrac{C(m,k)}{m}$。

## 完整代码
```cpp
#include <bits/stdc++.h>
using namespace std;

#define int long long
int prime[2000005]; // 预存阶乘

const int mod = 998244353;
// 快速幂
int qpow(int x, int y) {
    int a = 1;
    while (y) {
        if (y & 1)
            a = (a * x) % mod;
        x = (x * x) % mod;
        y >>= 1;
    }
    return a;
}
// 求 p/q mod意义下的逆元
int qinv(int p, int q) { return p * qpow(q, mod - 2) % mod; }
// 求 组合数 mod意义下的逆元
int C(int x, int y) {
    return prime[y] * qpow(prime[x] * prime[y - x] % mod, mod - 2) % mod;
}

void solve() {
    int n, m, c, a, b;
    cin >> n >> m >> c >> a >> b;
    a = qinv(a, b);
    b = (1 - a + mod) % mod;

    // 概率为 0 的情况
    if (n > m) {
        cout << 0 << '\n';
        return;
    }
    if ((m - n) % c != 0) {
        cout << 0 << '\n';
        return;
    }

    int k = (m - n) / c;
    int ans = -1;
    if (k == 0) { // 中奖数为 0
        ans = qpow(b, m);
    } else { // 中奖数非 0
        ans = qinv(n, m) % mod;
        ans = (ans * C(k, m)) % mod;
        ans = (ans * qpow(a, k)) % mod;
        ans = (ans * qpow(b, m - k)) % mod;
    }

    cout << ans << '\n';
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // 预处理阶乘
    int s = 1;
    prime[0] = 1;
    for (int i = 1; i < 2000002; i++) {
        s = s * i % mod;
        prime[i] = s;
    }

    int T;
    cin >> T;
    while (T--)
        solve();

    return 0;
}
```

## Raney 引理
Raney 引理告诉我们一句非常神奇的话：
>因为每一步最多向上爬 1 米，所以在这个圆环上，恰好有 $n$ 个点可以作为“安全的起点”。

为什么是恰好 $n$ 个？我画给你看：
把这个圆环画在坐标纸上。因为总高度上升了 $n$ 米，所以整个环看起来像是一个斜向上的大圈。
由于每一步最多向上 +1，你不可能跳过任何一个整数刻度。也就是说，当你从某个最低点开始走，高度从 1 米升到 2 米时，中间必须经历高度 1.5？不，因为是离散的，这里“恰好 $n$ 个”的严格数学证明用的是“最低点平移法”，但通俗地讲：
你可以把整个圆环“物理”地拿起来，放在一条水平线上。
因为总上升高度是 $n$，你可以在圆环上找到高度最低的那个点（设为 0 层）。
从最低点往上数，有第 1 层、第 2 层……直到第 $n$ 层。
由于每一步最多上升 1，每一层（1 到 $n$）在圆环上必定且只穿过一次“关键的最低点集合”。
这 $n$ 个不同的“层”对应了 $n$ 个不同的起点。从这些起点出发，后面永远高于起点。
