# A. 比特掩码
> 做题时间：2026-07-26
> 竞赛：2026牛客暑期多校训练营3
> 原题链接：https://ac.nowcoder.com/acm/contest/133878/A
## 题目简述
定义函数 $f(x)$ 表示非负整数 $x$ 的二进制表示（不含前导零）中，**极长连续全1段**的总个数。
给定长度为 $n$ 的整数数组 $a_1,a_2,\dots,a_n$，需要依次执行 $m$ 次全局位运算操作，操作分为三类：
1.  `type = 1`：将数组中每个元素替换为 $a_i \& x$（按位与）
2.  `type = 2`：将数组中每个元素替换为 $a_i | x$（按位或）
3.  `type = 3`：将数组中每个元素替换为 $a_i \oplus x$（按位异或）

要求在每一次操作完成后，输出当前数组所有元素的 $\sum_{i=1}^n f(a_i)$ 值。

## 做题思路
最初的解题思路上可以想到按二进制位整体统计，分别记录每一位上数字1、0的出现数量，但是卡在无法快速处理二进制中连续1段的变化；
关键：找到一个连续1段的性质，能够方便地储存、改变、计算连续1段
核心突破口：挖掘连续1段的判定性质——若某数二进制第 $i$ 位为1、第 $i+1$ 位为0，则代表此处存在一段连续1；
状态设计：如此一来，我们就将连续1段转化为第 $i$ 位和第 $i+1$ 位的0/1关系。对每个 $i$ 维护三维计数数组 `cnt[i][p][q]`
    含义：数组中满足「二进制第 $i$ 位为 $p$、第 $i+1$ 位为 $q$」的数字总个数；
    $p,q \in \{0,1\}$。
连续1段的数量就是对所有 `cnt[i][1][0]` 求和。
## 完整代码
```cpp
#include<bits/stdc++.h>
#define QwQ cin.tie(0)->sync_with_stdio(0);
#define all(A) A.begin(),A.end()
#define rall(A) A.rbegin(),A.rend()
using namespace std;
using ll = long long;
using ull = unsigned long long;
int main() {
    QwQ
    int n; cin >> n;
    int cnt[31][2][2]; // 维护的 cnt 数组
    memset(cnt, 0, sizeof cnt);
    // 输入部分：将数转化为 本位和下一位 的 01 关系
    for(int i=0; i<n; i++) {
        int x; cin >> x;
        bitset<31> bt(x);
        for(int i=0; i<30; i++) {
            cnt[i][bt[i]][bt[i+1]]++;
        }
    }
    // 操作部分
    int q; cin >> q;
    while(q--) {
        int tp, x;
        cin >> tp >> x;
        bitset<31> bt(x);
        if(tp == 1) { // 与 (&) 操作
            for(int i=0; i<30; i++) {
                if(bt[i] == 1) continue;
                // bt[i] == 0
                cnt[i][0][1] += cnt[i][1][1];
                cnt[i][0][0] += cnt[i][1][0];
                cnt[i][1][1] = cnt[i][1][0] = 0;
                if(i == 0) continue;
                cnt[i-1][0][0] += cnt[i-1][0][1];
                cnt[i-1][1][0] += cnt[i-1][1][1];
                cnt[i-1][0][1] = cnt[i-1][1][1] = 0;
            }
        } else if(tp == 2) { // 或 (|) 操作
            for(int i=0; i<30; i++) {
                if(bt[i] == 0) continue;
                // bt[i] == 1
                cnt[i][1][1] += cnt[i][0][1];
                cnt[i][1][0] += cnt[i][0][0];
                cnt[i][0][1] = cnt[i][0][0] = 0;
                if(i == 0) continue;
                cnt[i-1][0][1] += cnt[i-1][0][0];
                cnt[i-1][1][1] += cnt[i-1][1][0];
                cnt[i-1][0][0] = cnt[i-1][1][0] = 0;
            }
        } else { // 异或 (^) 操作
            for(int i=0; i<30; i++) {
                if(bt[i] == 0) continue;
                // bt[i] == 1
                swap(cnt[i][1][0], cnt[i][0][0]);
                swap(cnt[i][1][1], cnt[i][0][1]);
                if(i == 0) continue;
                swap(cnt[i-1][0][0], cnt[i-1][0][1]);
                swap(cnt[i-1][1][1], cnt[i-1][1][0]);
            }
        }
        // 输出部分
        int s = 0;
        for(int i=0; i<30; i++) {
            s += cnt[i][1][0];
        }
        cout << s << '\n';
    }
}
```
## 反思
1. 题目的突破口往往在其本身蕴含的性质当中
2. 补题时的状态转移有致命错误：仅更新 $i$ 位 与 $i+1$ 位的状态，没有更新与 $i-1$ 位的状态
