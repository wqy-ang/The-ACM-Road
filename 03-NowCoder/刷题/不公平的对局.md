# 不公平的对局

## 题目简述
小红和小紫正在对弈。在围棋规则中，每吃掉对方的一枚棋子，就需要将这枚棋子放入棋盖中。然而，棋盖空间不大，她们任何一方吃子数量达到 $x$ 就输了。

当然，我们不需要考虑具体的对弈局面，模型简化如下，每个回合将会依次执行以下两步：
- 小红有 $p_1$ 的概率吃掉对方一枚棋子；
- 小紫有 $p_2$ 的概率吃掉对方一枚棋子。

谁吃子数量达到 $x$ 就输了。小红执黑先手，她想知道自己最终获胜的概率是多少？你需要将答案对 $(10^9+7)$ 取模后输出。

> 这道题的核心是动态规划 + 概率归一化，只要把状态、转移、边界想清楚，以后遇到类似的“双方吃子到某数量就输/赢”的题，套路都一样。

## 1. 状态定义

设：

- $i$：小红已经吃掉的棋子数
- $j$：小紫已经吃掉的棋子数

定义： $dp[i][j]$

表示：**当前小红吃了 $i$ 个、小紫吃了 $j$ 个，且游戏还没结束时，小红最终获胜的概率。**

注意：

- 小红不希望自己先吃到 $x$ 个，因为那样她就输了。
- 小红希望小紫先吃到 $x$ 个，因为那样小紫输，小红赢。

所以边界是：

$dp[x][j] = 0$

表示小红已经吃到 $x$ 个，小红输了；

$dp[i][x] = 1$

表示小紫已经吃到 $x$ 个，小紫输了，小红赢了。

特别地：

$dp[x][x] = 0$

因为一回合中**小红先手**，如果同一回合双方都到 $x$，小红先到，所以小红输。

---

## 2. 一回合会发生什么？

当前状态是 (i,j)，一回合分两步：

1. 小红有概率 $p_1$ 吃掉一个子；
2. 小紫有概率 $p_2$ 吃掉一个子。

四种情况：

| 情况 | 概率 | 结果 |
|---|---|---|
| 红吃，紫吃 | $p_1p_2$ | 小红、小紫都 +1 |
| 红吃，紫不吃 | $p_1(1-p_2)$ | 小红 +1 |
| 红不吃，紫吃 | $(1-p_1)p_2$ | 小紫 +1 |
| 红不吃，紫不吃 | $(1-p_1)(1-p_2)$ | 状态不变，相当于本轮无效 |

其中最后一种情况会让游戏回到原状态，所以不能直接忽略，而是可以合并到左边。

## 3. 写出转移方程

设：

$$
S=p _1 (1−p _2 )+(1−p _1 )p _2 +p _1p _2
$$
也就是“本轮至少有一方吃子”的总概率：

$$
S=p _1+p _2−p _1p _2
$$
显然：

$$
dp[i][j] = (1−p_ 1 )(1−p_2
 )dp[i][j] + p_1
 (1−p_2
 )dp[i + 1][j] + (1−p_1
 )p_2
 dp[i][j + 1] + p_1
 p_2
 dp[i + 1][j + 1]
$$
把左边第一项移到右边：

$$
S\cdot dp[i][j]
=
p_1(1-p_2)dp[i+1][j]
+
(1-p_1)p_2dp[i][j+1]
+
p_1p_2dp[i+1][j+1]
$$
所以：

$$
dp[i][j]
=
\frac{
p_1(1-p_2)dp[i+1][j]
+
(1-p_1)p_2dp[i][j+1]
+
p_1p_2dp[i+1][j+1]
}{
S
}
$$
这就是题解里的转移方程。

---

## 4. 为什么可以这样算？

因为 $(i,j)$ 只会增加，不会减少，所以我们可以从边界倒推：

- 先确定所有 $dp[x][j]$ 和 $dp[i][x]$
- 然后从 $i=x-1$ 到 $0$，从 $j=x-1$ 到 $0$ 计算

每一步用到的：

$$
dp[i+1][j],\quad dp[i][j+1],\quad dp[i+1][j+1]
$$
都是已经算好的边界值或更大的状态值。

---

## 5. 模意义下如何处理概率？

题目给的 $p_1=\frac{a_1}{b_1}$，$p_2=\frac{a_2}{b_2}$。

在模 $10^9+7$ 下：

$$
p_1 = a_1 \cdot b_1^{-1} \bmod M
$$

$$
p_2 = a_2 \cdot b_2^{-1} \bmod M
$$

转移里面有除法 $\frac{1}{S}$，就用：

$$
S^{-1} \bmod M
$$
也就是乘法逆元。

因为题目保证最终分母不是 \(M\) 的倍数，所以可以放心求逆元。

## 6. C++ 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;
const ll MOD = 1000000007;

ll mod_pow(ll a, ll e) {
    ll res = 1;
    while (e) {
        if (e & 1) res = res * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return res;
}

ll inv(ll x) {
    return mod_pow(x, MOD - 2);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int x;
    cin >> x;

    ll a1, b1, a2, b2;
    cin >> a1 >> b1;
    cin >> a2 >> b2;

    ll p1 = a1 % MOD * inv(b1 % MOD) % MOD;
    ll p2 = a2 % MOD * inv(b2 % MOD) % MOD;

    ll np1 = (1 - p1 + MOD) % MOD; // 1 - p1
    ll np2 = (1 - p2 + MOD) % MOD; // 1 - p2

    // 有效概率 S = 1 - (1-p1)(1-p2)
    ll S = (p1 + p2 - p1 * p2 % MOD + MOD) % MOD;
    ll invS = inv(S);

    vector<vector<ll>> dp(x + 1, vector<ll>(x + 1, 0));

    // 小红已经吃到 x 个：小红输
    for (int j = 0; j <= x; j++) {
        dp[x][j] = 0;
    }

    // 小紫已经吃到 x 个：小紫输，小红赢
    for (int i = 0; i < x; i++) {
        dp[i][x] = 1;
    }

    // 双方同时到 x，小红先手，小红输
    dp[x][x] = 0;

    for (int i = x - 1; i >= 0; i--) {
        for (int j = x - 1; j >= 0; j--) {
            ll val = 0;

            // 红吃，紫不吃
            val = (val + p1 * np2 % MOD * dp[i + 1][j]) % MOD;

            // 红不吃，紫吃
            val = (val + np1 * p2 % MOD * dp[i][j + 1]) % MOD;

            // 红吃，紫吃
            val = (val + p1 * p2 % MOD * dp[i + 1][j + 1]) % MOD;

            dp[i][j] = val * invS % MOD;
        }
    }

    cout << dp[0][0] << '\n';

    return 0;
}
```

---

## 7. 重要易错点

- 边界 $dp[x][x]$ 必须是 $0$，不能是 $1$。
- 转移时 $p_1(1-p_2)$ 对应的是：红吃、紫不吃。
- 转移时 $(1-p_1)p_2​$ 对应的是：红不吃、紫吃。
- 转移时 $p_1p_2$ 对应的是：都吃。
- 模运算中减法要 $+MOD$ 再取模，防止负数。
- 分母 $S$ 要用逆元，不能直接除。

## 8. 举一反三总结

以后遇到类似题目：

1. 找状态：通常用“当前双方累计数量”作为状态。
2. 找边界：谁先达到目标谁输/赢。
3. 写转移：枚举当前回合所有情况，把“状态不变”的情况移到等式左边。
4. 注意先后手顺序：如果同时触发条件，先手方先触发。
5. 概率用模意义下的逆元表示。
