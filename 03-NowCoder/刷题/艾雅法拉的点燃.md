# F. 艾雅法拉的点燃
> 做题时间：2026-07-28

> 比赛：牛客周赛 Round 154

> 原题链接：https://ac.nowcoder.com/acm/contest/137840/F

## 题目简述
有 $n$ 名敌人从左至右排成一列，第 $i$ 名敌人初始生命值为 $a_i$；生命值 $>0$ 代表敌人存活。
每次行动需要选择一名存活敌人作为目标，二选一执行攻击：
1. **普通攻击**：消耗 $x$ 法力，目标生命值 $-1$。
2. **技能「点燃」**：消耗 $y$ 法力，目标生命值 $-2$；目标左右相邻敌人生命值各 $-1$，边界无相邻则不产生对应伤害。

规则补充：
敌人位置、相邻关系固定，不受生命值是否归零影响；生命值允许降至 $0$ 以下。

求将所有敌人生命值全部打至不大于 $0$ 的最小总法力消耗。

## 解题思路与DP心得
在讲之前，我们要先统一一个认知：虽然我给的代码里 `dp` 是**二维数组**（`dp[prev][cur]`），但我们把它叫做“三维 DP”，是因为它的**转移过程**要枚举三个未知数（`prev`, `cur`, `nxt`），所以复杂度是 $O(n\cdot M^3)$。

下面，我带你一步一步从“直觉”走到“代码实现”，把问题转化为“选点燃次数”。

---

### 第一步：定义核心变量（解题的“灵魂”）
我们设第 `i` 个敌人被施放“点燃”的次数为 `S_i`。
- 范围：`S_i` 是非负整数。
- 为了公式统一，我们令 **虚拟边界**： $S_0 = 0$， $S_{n+1} = 0$

**为什么这么设？**
因为敌人 `i` 会受到三种点燃伤害：
1. 自己身上的点燃： $2 \times S_i$
2. 左边敌人溅射过来： $S_{i-1}$
3. 右边敌人溅射过来： $S_{i+1}$

所以，敌人 `i` 总共受到的点燃伤害满足：

$$
\mathrm{fire\_damage}_i = S_{i-1} + 2S_i + S_{i+1}
$$

如果点燃没打死，剩下的血就用普通攻击补刀。因此普通攻击次数为：

$$
\mathrm{normal}_i = \max(0,\ a_i - (S_{i-1} + 2S_i + S_{i+1}))
$$

总花费为所有点燃消耗与普通攻击消耗之和：

$$
\mathrm{total\_cost} = \sum_{i=1}^{n} \big( y \cdot S_i + x \cdot \mathrm{normal}_i \big)
$$

**这就是思考的基石：一旦确定了所有的 $S_1$ 到 $S_n$，答案就确定了。** 我们 DP 的任务就是找出怎么分配这些 `S_i` 最省钱。

---

### 第二步：为什么 DP 状态要保留两个数？
我们按顺序从左往右处理敌人（从第 1 个处理到第 `n` 个）。
假设现在要计算敌人 `i` 需要多少普通攻击，公式是：

$$
\mathrm{normal}_i = \max(0,\ a_i - S_{i-1} - 2S_i - S_{i+1})
$$

你会发现，算第 `i` 个敌人的花费时，**需要用到未来变量 $S_{i+1}$**！
也就是说，当我们站在 `i` 的位置时，右边的点燃次数还没决定。

为了解决这个“未来依赖”问题，我们决定：**处理完前 `i-1` 个敌人时，手里必须攥着未来一步的信息。**

于是定义 DP 状态：

$$
dp[\mathrm{prev}][\mathrm{cur}]
$$

- 含义：已经**处理完**第 1 到第 `i-1` 个敌人的花费（即 `1 ~ i-1` 的普通攻击和点燃费用都已算清）。
- 前提条件：此时我们知道 $S_{i-1} = \mathrm{prev}$，且 $S_i = \mathrm{cur}$。
- 值：当前这种状态下的最小总花费。

因为处理到第 `i` 个敌人时，我们要枚举 $S_{i+1} = \mathrm{nxt}$，有了 `prev, cur, nxt`，刚好能把第 `i` 个敌人的花费算出来。

---

### 第三步：初始状态（第 1 个敌人之前）
我们还没开始处理任何敌人。此时 `i=1`。
- 虚拟边界 $S_0 = 0$，所以 `prev = 0`。
- $S_1$ 可以是任意合理的值（`0` 到 `M`），记为 `cur`。

虽然还没处理敌人 1，但我们知道 $S_1 = \mathrm{cur}$，我们需要**提前支付** $S_1$ 带来的点燃消耗，即 $y \cdot \mathrm{cur}$。

所以初始化：

$$
dp[0][\mathrm{cur}] = y \cdot \mathrm{cur} \quad (0 \le \mathrm{cur} \le M)
$$

其他状态全设为无穷大（不可达）。

---

### 第四步：转移过程（三层循环的真相）
现在开始处理第 `i` 个敌人（`i` 从 1 到 `n`）。
我们要构造新的 DP 表 `new_dp`，表示处理完第 `i` 个敌人后的状态。
**新的状态**将由 $S_i$ 和 $S_{i+1}$ 决定，即 `new_dp[cur][nxt]`。

要算出这个值，我们必须依赖旧状态 `dp[prev][cur]`，并枚举 `nxt`。
于是，**暴力三重循环**诞生了：

```text
for prev in 0..M:        // 枚举 S_{i-1}
  for cur in 0..M:       // 枚举 S_i
    if dp[prev][cur] 不可达: 跳过
    for nxt in 0..M:    // 枚举 S_{i+1}
      计算敌人 i 的普通攻击次数
      更新 new_dp[cur][nxt]
```

我们把“计算第 `i` 个敌人”的公式代进去：
1. **点燃总伤害**：$\mathrm{damage} = \mathrm{prev} + 2 \cdot \mathrm{cur} + \mathrm{nxt}$
2. **需要补刀的次数**：$\mathrm{need} = a[i] - \mathrm{damage}$，如果小于 0 就取 0（溢出无影响）。
3. **普通攻击花费**：$\mathrm{need} \times x$
4. **当前状态已有的花费**：$dp[\mathrm{prev}][\mathrm{cur}]$
5. **提前支付 $S_{i+1}$ 的点燃费用**：$y \cdot \mathrm{nxt}$（$S_{i+1}$ 在本步确定，同步计入消耗）

所以转移方程就是：

$$
\mathrm{new\_dp}[\mathrm{cur}][\mathrm{nxt}] = \min\Big(
\mathrm{new\_dp}[\mathrm{cur}][\mathrm{nxt}],\ 
dp[\mathrm{prev}][\mathrm{cur}] + x \cdot \max(0,\ a_i - \mathrm{prev} - 2\mathrm{cur} - \mathrm{nxt}) + y \cdot \mathrm{nxt}
\Big)
$$

---

### 第五步：图解遍历过程（手推小例子）
假设现在只有 1 个敌人（`n=1`），初始生命 `a_1=5`，`x=1, y=100`（点燃很贵）。

- 初始化：`dp[0][0]=0`、`dp[0][1]=100`、`dp[0][2]=200` …
- 处理 `i=1`：
  - 枚举 `prev=0`（因为 $S_0=0$）。
  - 枚举 `cur=0`（不对自身释放点燃）。
    - 枚举 `nxt=0`（$S_2=0$ 为边界，暴力版会枚举所有 `nxt`，但非0值必然不优）。
    - 计算得 `need = 5 - 0 - 0 - 0 = 5`，总花费 `0 + 5 × 1 + 0 × 100 = 5`。
  - 枚举 `cur=2`（对自身点燃 2 次，前置花费 200）。
    - 枚举 `nxt=0`。
    - 计算得 `need = 5 - 0 - 4 - 0 = 1`，总花费 `200 + 1 × 1 + 0 = 201`。

暴力版会枚举很多无用的 `nxt`（比如 `nxt=100`），导致 `need` 变成负数被截断为 0，但多支付了大量点燃费用，显然不是最优解，但程序仍会完整计算。

**核心理解**：每个敌人 `i` 的结算，都必须等到枚举了 `nxt` 才能进行。这就叫“延迟结算”。

---

### 第六步：为什么 M 要取 `max(a_i) + 2`？
任何 `S_i` 如果大于等于 `a_i + 2`，它造成的伤害已经远远超过了敌人的最大血量。
- 如果某个 `S_i` 取值过大，我们完全可以把多余的“点燃”换成“普通攻击”，花费只会更低（点燃除了自身 2 点伤害还有溅射，但溢出的溅射伤害是纯浪费）。
- 数学上可以证明，最优解中每个 `S_i` 都不会超过 $\max(a_i) + 1$。因此取 $M = \max(a_i) + 2$ 作为循环上界，可保证最优解一定在枚举范围内。

---

### 第七步：收尾（最后一步）
循环处理完 `i = n` 后，我们得到了最终的 `dp` 表，代表处理完第 `n` 个敌人后的所有状态。
此时必须强制满足边界条件 $S_{n+1} = 0$，我们枚举所有 $S_n = \mathrm{cur}$ 的情况取最小值。

所以最终答案是：

$$
\mathrm{ans} = \min_{0 \le \mathrm{cur} \le M} dp[\mathrm{cur}][0]
$$

---

### 第八步：时间复杂度与运行直觉
- **空间**：二维滚动数组，$O(M^2)$。
- **时间**：三层循环 `prev × cur × nxt`，单次转移为 $O(M^3)$，总复杂度为 $O(n \cdot M^3)$。
- **直观示例**：如果 $\max(a_i) = 100$，取 $M=102$，单层循环约 100 万次，乘上 `n=100` 约 1 亿次运算，勉强可运行；但若 $\max(a_i) = 300$，$M^3$ 可达 2700 万，乘 `n` 后会严重超时。

这就是为什么需要优化。未优化版中，**内层的 `nxt` 枚举了大量无用情况**，优化版可利用前缀/后缀最小值消去一层循环，大幅提升效率。

---

### 总结：三维 DP 的思考流程图

1. **设变量**：把点燃次数 $S_i$ 设出来。
2. **找依赖**：发现第 $i$ 个敌人的花费依赖 ($S_{i-1}$, $S_i$, $S_{i+1}$)。
3. **定状态**：因为依赖未来，所以 DP 存最近的两个变量 `(prev, cur)`。
4. **暴力转移**：枚举未来的 `nxt`，把当前敌人结算掉，存入新状态 `(cur, nxt)`。
5. **定边界**：($S_0$ = $S_{n+1}$ = $0$)，初始和收尾处理好。

## 完整代码
```cpp
#include<bits/stdc++.h>
#define QwQ cin.tie(0)->sync_with_stdio(0);
using namespace std;
using ll = long long;

const ll INF = 1e18;

int main() {
    QwQ
    // 初始化部分
    int n;
    ll x, y;
    cin >> n >> x >> y;
    vector<int> a(n+2);
    int M = 0;  // M：点燃次数的上限
    for(int i=1; i<=n; i++) {
        cin >> a[i];
        M = max(M, a[i]);
    }
    M += 2;

    // dp[prev][cur] 表示：
    // 处理完前 i-1 个敌人后，S_{i-1}=prev, S_i=cur 的最小消耗
    vector<vector<ll>> dp(M, vector<ll>(M, INF));

    // 初始状态：i = 1 之前，S_0 = 0，S_1 = cur
    // 需要先支付 S_1 的点燃费用
    for(int cur = 0; cur < M; cur++) {
        dp[0][cur] = y * cur;
    }

    // 依次处理敌人 1 到 n
    for(int i=1; i<=n; i++) {
        // new_dp[cur][nxt] 表示处理完第 i 个敌人后，S_i=cur, S_{i+1}=nxt
        vector<vector<ll>> new_dp(M, vector<ll>(M, INF));
        // 枚举 S_{i-1} = prev
        for(int pre=0; pre<M; pre++) {
            // 枚举 S_i = cur
            for(int cur=0; cur<M; cur++) {
                if(dp[pre][cur] == INF) continue;

                // 枚举 S_{i+1} = nxt
                for(int nxt=0; nxt<M; nxt++) {
                    // 敌人 i 受到的点燃伤害 = S_{i-1} + 2*S_i + S_{i+1}
                    ll damage = pre + 2*cur + nxt;
                    // 剩余血量 即 需要普通攻击补足的次数
                    ll res = a[i] - damage;
                    if(res < 0) res = 0;

                    // 转移：加上普通攻击的花费，以及 S_{i+1} 的点燃花费
                    ll cost = dp[pre][cur] + x*res + y*nxt;

                    new_dp[cur][nxt] = min(new_dp[cur][nxt], cost);
                }
            }
        }
        dp = move(new_dp);
    }

    // 最终 S_{n+1} 必须为 0
    ll ans = INF;
    for(int cur=0; cur<M; cur++) {
        ans = min(ans, dp[cur][0]);
    }

    cout << ans << '\n';
}
```
